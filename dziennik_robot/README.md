# Dziennik Robót

Manifest dodatku Home Assistant. Kod aplikacji znajduje się w obrazie
`ghcr.io/romean5/dziennik-robot-home-assistant`.

Dodaj do Home Assistant repozytorium:

`https://github.com/Romean5/dziennik-robot-home-assistant`

Instalacja z tego repozytorium tworzy nową tożsamość dodatku. Przed migracją
z lokalnego dodatku wykonaj kopię zapasową danych; nie usuwaj działającego
dodatku przed potwierdzonym przywróceniem danych.
